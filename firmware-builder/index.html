Flashing help

Direct flash from this page

  1. Connect ESP32-C3 to USB using a data cable.
  2. Build firmware, then press Connect ESP.
  3. Select the ESP serial port in the browser dialog.
  4. Confirm the detected chip is ESP32-C3.
  5. Press Flash firmware and wait until it finishes.

Android direct-flash test: open this page in WebSerial USB APK v1.8, connect with OTG, and check whether the serial-device picker appears. If it does not, use the Android merged-BIN method instead.

Flash merged.bin using a PC

  1. Download merged.bin.
  2. Open a compatible ESP32 flashing tool or use Espressif esptool.
  3. Select ESP32-C3 and set flash address to 0x0000.
  4. Choose DIO, 80 MHz, 4 MB, then flash.

Flash merged.bin using Android

  1. Download merged.bin to your phone.
  2. Install ESP Flash app.
  3. Connect the board with a USB OTG adapter and data cable.
  4. Choose the BIN, ESP32-C3, and address 0x0000.
  5. Use DIO, 80 MHz and 4 MB flash settings, then flash.

App interface and chip options may vary by version.

What is Advanced BIN?

The ZIP contains separate binary files. Flash each file at the exact address in FLASH-INSTRUCTIONS.txt. Current standard offsets are bootloader 0x0000, partitions 0x8000, app 0x10000; Arduino variants also include boot_app0.bin at 0xE000. Use files from one ZIP only. Never mix builds.
